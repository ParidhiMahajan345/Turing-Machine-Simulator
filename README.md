# Turing Machine Simulator
An interactive Turing Machine Simulator designed to demonstrate
computational theory and fundamental operations through
interactive HTML-based simulations.
## Features
- Interactive Turing Machine simulations
- Binary addition
- Binary increment
- Unary addition
- Unary increment
- Palindrome recognition
- Multiple simulation pages
## Technologies Used
- HTML
- CSS
- JavaScript
## How to Run
Open `index.html` in your web browser.
