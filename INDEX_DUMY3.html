Learn the Core Concepts

Understand the foundations of computation through simple visual ideas

🤖

Turing Machine

A Turing Machine is a simple mathematical model that explains how a computer works. It uses a tape, a head, and states to read, write, and move step-by-step to solve problems.

🔁

Palindromes

A palindrome is a string that reads the same forward and backward. The machine checks symbols from both ends to decide whether the input is symmetric.

➕

Binary Addition

Binary addition works with 0s and 1s. The machine simulates how computers add numbers using carry and simple state transitions.

⬆️

Binary Increment

Binary increment adds 1 to a binary number. The machine flips bits from right to left until the addition is complete.

🟦

Unary Addition

Unary addition uses only one symbol (like 1). Numbers are added by combining symbols, making the logic very easy to visualize.

🚀

Unary Increment

Unary increment increases a number by adding one more symbol to the tape. It shows how even simple rules can compute values.
